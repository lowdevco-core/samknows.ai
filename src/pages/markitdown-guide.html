MarkItDown is a free Microsoft tool that turns files into Markdown. Feed Claude the Markdown instead of the original PDF, Word or PowerPoint file and it reads far less, so your tokens and usage limits stretch further. Setup takes about 5 minutes and one pip command.

Key takeaways

  • MarkItDown converts PDF, Word, PowerPoint, Excel, HTML, CSV, JSON, ZIP, EPub and more into Markdown.
  • Install it with pip install "markitdown[all]". Python 3.10 to 3.14 is the only requirement.
  • Convert with one command: markitdown file.pdf -o file.md, then give Claude the .md.
  • Scanned PDFs need an OCR add-on. Keep your originals; the Markdown is a working copy.

What is MarkItDown?★

MarkItDown is a free, open-source Python tool from Microsoft that turns files into Markdown. You give it a PDF, a Word file, a PowerPoint, an Excel sheet or a web page, and it gives you back plain text with the structure kept: headings, lists, tables and links.

It was built for feeding documents to AI models, not for making pretty copies for people. The source is at github.com/microsoft/markitdown.

Why does Markdown save Claude tokens?★

Claude pays for everything it reads in tokens, and your plan's usage limits are counted in tokens too. A file carries a lot more than its words: layout, fonts, styling and, for PDFs, the page itself. When you upload a PDF, Claude can read each page as both extracted text and an image, so a long PDF uses up your context fast.

A Markdown copy keeps only the words and the structure that gives them meaning. The MarkItDown README puts it simply: Markdown is close to plain text, models understand it well, and its conventions are token-efficient. Less to read means more room left in the chat for your actual question, and fewer “conversation too long” moments.

The easiest way to see the difference is to try one of your own files: upload the original in one chat, the .md version in another, and compare how much of your usage each one takes.

What do you need before you start?★

You need Python 3.10 to 3.14 on your computer. That's the only requirement. Check your version with:

python --version

On a Mac or Linux the command may be python3 instead. If you don't have Python, install it from python.org first. Using Claude Code? You can also ask Claude to do every step below for you.

How do you install MarkItDown?★

Make a virtual environment first, so MarkItDown's packages don't clash with anything else on your computer. Then install it with pip.

Step 1: make a virtual environment★

On Mac or Linux:

python3 -m venv .venv
source .venv/bin/activate

On Windows (PowerShell):

python -m venv .venv
.venv\Scripts\Activate.ps1

Step 2: install MarkItDown★

This installs MarkItDown with support for every file type:

pip install "markitdown[all]"

The double quotes matter. They make the same command work in PowerShell, Command Prompt and the Mac terminal.

Step 3: check that it worked★

markitdown --help

If you see the help text, you're ready. If the command isn't found, the virtual environment isn't active. Run the activate line from Step 1 again.

How do you convert a file to Markdown?★

One command. Point it at a file and choose where the Markdown goes with -o:

markitdown report.pdf -o report.md

Without -o it prints to the screen, so you can also redirect it:

markitdown slides.pptx > slides.md

Got a whole folder of PDFs? On Mac or Linux:

for f in *.pdf; do markitdown "$f" -o "${f%.pdf}.md"; done

On Windows (PowerShell):

Get-ChildItem *.pdf | ForEach-Object { markitdown $_.FullName -o ($_.BaseName + ".md") }

Swap *.pdf for *.docx, *.pptx or *.xlsx to do other file types the same way.

How do you use the Markdown with Claude?★

Once you have the .md file, use it anywhere you'd have used the original:

  • In a Claude chat: attach the .md file instead of the PDF or Word file, or paste its text straight into the message.
  • In a Claude Project: add the .md files to the project's knowledge. Every chat in the project then reads the lighter version.
  • In Claude Code: save the Markdown inside your project and point Claude at it, for example @docs/report.md, instead of the original file.

In Claude Code you don't even have to run the commands yourself. Once MarkItDown is installed, paste something like this:

Convert every PDF in the docs folder to Markdown with markitdown, save each one next to the original, then read the Markdown versions instead of the PDFs.

Keep the original files. The Markdown is your working copy for Claude, not a replacement.

Which file types can it convert?★

markitdown[all] installs support for everything. If you only need a few types, install just those, for example pip install "markitdown[pdf,docx,pptx]".

File typeInstall extraWhat you get
PDF[pdf]Text, headings and tables from text-based PDFs
Word[docx]Headings, lists, tables and links
PowerPoint[pptx]Slide text, notes and tables
Excel[xlsx], [xls]Each sheet as a Markdown table
Outlook messages[outlook]The email as text
HTML, CSV, JSON, XMLbuilt inClean text and tables
ZIP filesbuilt inConverts each file inside
EPubbuilt inBook text with chapters as headings
Imagesbuilt inEXIF metadata; captions need an AI model
Audio[audio-transcription]Metadata and a speech transcript (wav, mp3)
YouTube links[youtube-transcription]The video's transcript

Image captions and speech transcription use web-hosted services, so those two need an internet connection and, for captions, an AI model you connect yourself.

Can you use it from Python?★

Yes. This is handy if you want to convert files inside your own script:

from markitdown import MarkItDown

md = MarkItDown(enable_plugins=False)
result = md.convert_local("report.pdf")
print(result.markdown)

convert_local() only reads local files. MarkItDown also has a broader convert() that can fetch URLs, but the README recommends using the narrowest method you need.

What can MarkItDown not do?★

It isn't a perfect copy machine. The output is made for AI tools to read, so complex layouts, columns and design details get flattened. If you need a faithful copy for people to read, keep the original.

Scanned PDFs are the big one. A scanned page is a picture of text, and the built-in PDF converter can't read pictures. For those you need OCR: the markitdown-ocr plugin (which uses an AI vision model) or Microsoft's paid Azure Document Intelligence service.

And one safety note from the README: MarkItDown can open anything your user account can open, including URLs. Only convert files you trust, and don't wire it up to take files from strangers without checks.

FAQ★

Is MarkItDown free?★

Yes. It's open source from Microsoft and free to install with pip. The only paid parts are optional Azure services you'd have to set up yourself.

Does it work offline?★

The normal converters for PDF, Word, PowerPoint, Excel, HTML and text formats run on your computer. Image captions, speech transcription and the Azure options use online services.

Does it work on Windows?★

Yes. It's a Python tool, so it runs on Windows, Mac and Linux. Use the PowerShell commands above on Windows.

Will Claude understand the tables?★

Yes. Tables come out as Markdown tables, which Claude reads well. Very wide or merged-cell tables can come out messy, so check the important ones.

Can it read scanned PDFs?★

Not on its own. Add the markitdown-ocr plugin or use Azure Document Intelligence, as explained in the limits section.
